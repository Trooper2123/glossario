# Banco de Dados

**Categoria:** Backend | **Data de Revisão:** 19/05/2026

## O que é?
Um banco de dados é uma coleção organizada de dados, geralmente armazenada e acessada eletronicamente a partir de um sistema de computador.

## Tipos Principais
- **Relacional (SQL):** MySQL, PostgreSQL, Oracle.
- **Não-Relacional (NoSQL):** MongoDB, Redis, Cassandra.
