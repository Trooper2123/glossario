# API (Application Programming Interface)

**Categoria:** Desenvolvimento Web | **Data de Revisão:** 19/05/2026

## O que é?
Uma API é um conjunto de definições e protocolos usado para integrar softwares. É como um "garçom" que leva o seu pedido (request) até a cozinha (servidor) e traz o seu prato (response).

## Exemplo de uso
Quando você usa um aplicativo de clima no celular, o app consome uma API para buscar os dados de temperatura no servidor e mostrar na sua tela.
